Resources & Workflow

        

          

            
Typical workflow

            
    
              
  1. Projects — create / open a bid
    2. 
              
  2. Cover Sheet — job info & contacts
    3. 
              
  3. Takeoff — load plan, set scale, conditions, layers, draw
    4. 
              
  4. Summary — review quantities
    5. 
              
  5. Estimate — apply unit costs
    6. 
              
  6. Worksheet — allowances & adjustments
    7. 
            

          

          

            
Scale

            
Pick a preset (e.g. ¼" = 1'-0") or Calibrate: click two points on a known dimension, then enter the real length in feet.

          

          

            
Conditions & Layers

            
Conditions are measurable building objects (walls, floors, fixtures). Styles: Linear, Area, Count.

            
Layers organize takeoff — toggle visibility like transparent sheets.

          

          

            
Hidden tabs

            
Like classic OST, some tabs only appear when a bid is open. Budget and Notes are optional — use Show / Hide Tabs to reveal them.

          

          

            
Shortcuts

            
    
              
  • V / L / A / C / P — Select / Linear / Area / Count / Pan
    • 
              
  • 1–9 — arm condition by number · Tab — next condition
    • 
              
  • Mouse wheel — zoom · middle / right-drag — pan when idle
    • 
              
  • Space or right-click — finish mark (or pan if not drawing)
    • 
              
  • Shift — ortho · Enter / double-click — finish · Esc — cancel
    • 
              
  • Delete — remove selected · Ctrl+Z / Ctrl+Y — undo / redo
    • 
            

          

          

            
Estimates folders

            
Launch with Launch PlanTakeoff.bat so the local server can read Samuel Bids\Estimates YYYY and create new EST folders (same as FOLDERS.bat).

          

          

            
About this app

            
Standalone takeoff for WL Painting. Not mixed with WL Platform CRM. Separate from proprietary OST.
